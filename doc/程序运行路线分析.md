## 程序运行路线详解

### 第一阶段：硬件复位和电源初始化

**日志：**
```
P3 Reset Source : 0x1
VDDIO POR
board_power_wakeup_init
board_power_wakeup_init ok
```

**分析：**
- **P3 Reset Source: 0x1** - P3复位源为0x1，表示上电复位（POR - Power On Reset）
- **VDDIO POR** - VDDIO电源上电复位触发
- **board_power_wakeup_init** - 执行板级电源唤醒初始化
- 初始化完成后输出 "ok"

**涉及模块：**
- 硬件复位控制器
- 电源管理单元（PMU）

---

### 第二阶段：文件系统初始化（SDFILE）

**日志：**
```
[Info]: [SDFILE]VM size: 0x8100 @ 0x76e00
[Info]: [SDFILE]disk capacity 1024 KB
[Debug]: [SDFILE]sdfile mount succ
```

**分析：**
- **VM size: 0x8100 @ 0x76e00** - 虚拟机（Virtual Machine）大小：0x8100（32KB），存储地址在0x76e00
- **disk capacity 1024 KB** - 磁盘容量：1024KB（1MB）
- **sdfile mount succ** - SD文件系统挂载成功

**说明：**
杰理SDK使用SDFILE作为Flash文件系统，用于：
- 存储用户配置参数
- 存储蓝牙配对信息
- 存储音频资源文件
- 存储固件升级包

**涉及文件：**
- `apps/soundbox/board/br25/board_ac696x_demo/board_ac696x_demo.c`

---

**分析：**
- **Power init** - 板级电源初始化开始

- **vbat_adc_value = 406** - 电池ADC采样值：406（用于电量计算）
- **vbg_adc_value = 380** - 基准电压ADC值：380（用于ADC校准）
- **add sample ch 50000f** - 添加采样通道（可能是电池电压采样）

**涉及模块：**
- ADC（模数转换器）
- 电池电压检测电路
- 电源管理

```

[Info]: [APP-UPDATE]<--------update_result_deal=0x5a00 7b19--------->
```

**分析：**
- **testbox msg handle reg** - 注册测试盒消息处理函数（地址0x1e41c70）

- **update_result_deal** - 检查固件更新结果
  - 0x5a00可能是更新状态码
  - 7b19可能是版本号或校验值

**涉及模块：**
- 测试盒通信接口
- 固件升级模块（OTA）

### 第六阶段：音频编解码初始化

**日志：**
```
audio_enc_init
audio_dec_init
[Info]: [AUDIO-DAC]audio_dac_init
```

**分析：**
- **audio_enc_init** - 音频编码器初始化
  - 用于麦克风音频采集和编码
  - 支持SBC、AAC、mSBC等编码格式
- **audio_dec_init** - 音频解码器初始化
  - 用于蓝牙音频流解码
  - 支持SBC、AAC、LDAC等解码格式
- **audio_dac_init** - DAC（数模转换器）初始化
  - 配置DAC输出参数
  - 设置采样率、位深等

**涉及模块：**
- 音频编码器（Audio Encoder）
- 音频解码器（Audio Decoder）
- DAC驱动

### 第十阶段：蓝牙回连流程

**日志：**
```
[Debug]: [BT]connect_switch: 0, 12000
edr_hid:remote_type= 1
[Debug]: [BT]remote_name : 欧小红的Xiaomi 15
A6 BE 7B 93 8B 94
[Debug]: [BT]-----------------------bt_connction_status_event_handler 5
[Info]: [BT] BT_STATUS_START_CONNECT EDR
```

**分析：**
- **connect_switch: 0, 12000** - 连接开关状态
  - 0：可能是第一次连接或回连标志
  - 12000：连接超时时间（12秒）
- **edr_hid:remote_type= 1** - EDR HID远端设备类型：1（手机）
- **remote_name: 欧小红的Xiaomi 15** - 已配对的远端设备名称
- **A6 BE 7B 93 8B 94** - 远端设备MAC地址
- **BT_STATUS_START_CONNECT EDR** - 开始EDR（经典蓝牙）连接

**连接类型说明：**
- **EDR** - Enhanced Data Rate，经典蓝牙，用于A2DP音频、HFP通话
- **BLE** - Bluetooth Low Energy，低功耗蓝牙，用于广播、配对

**涉及模块：**
- 蓝牙配对信息管理
- 蓝牙连接调度器
- EDR连接管理

**涉及模块：**
- HCI层

- 安全管理

### 第十二阶段：HFP协议交互

**日志：**
```

[Debug]: [BT]-----------------------bt_connction_status_event_handler 13
[Info]: [BT]BT_STATUS_PHONE_MANUFACTURER
```

**分析：**
标准的HFP（Hands-Free Profile）AT命令交互：

| AT命令 | 说明 |
|--------|------|
| AT+BRSF=16 | 查询手机支持的HFP特性（位掩码） |
| AT+BAC=1,2 | 设置可用编解码器（1=CVSD, 2=mSBC） |
| AT+CIND=？| 查询指示器支持列表 |
| AT+CIND? | 查询当前指示器状态 |
| AT+CMER=3,0,0,1 | 开启事件上报（指示器变化通知） |
| AT+CHLD=？| 查询通话保持能力 |
| AT+CMEE=1 | 开启扩展错误码 |

**BT_STATUS_PHONE_MANUFACTURER** - 获取到手机制造商信息

**HFP功能：**
- 免提通话
- 通话记录同步
- 电话簿访问
- 语音识别

**涉及模块：**
- HFP协议栈
- AT命令解析器
- 电话功能模块

- 手机和设备双向同步

## 蓝牙状态机

```
BT_STATUS_INIT_OK (初始化完成)
        ↓
BT_STATUS_START_CONNECT EDR (开始连接)
        ↓
HCI_EVENT_CONNECTION_COMPLETE (HCI连接完成)
        ↓
BT_STATUS_ENCRY_COMPLETE (加密完成)
        ↓
BT_STATUS_PHONE_MANUFACTURER (获取手机信息)
        ↓
BT_STATUS_CALL_VOL_CHANGE (音量同步)
        ↓
BT_STATUS_CONNECTED (连接完成)
        ↓
BT_STATUS_RECONN_OR_CONN (重连/稳定连接)
```

---

## 音频数据流

```
手机音频 → A2DP编码 → 蓝牙传输 → 解码器 → DAC → 扬声器
                              ↓
麦克风 → ADC → 编码器 → HFP传输 → 手机
```

## 调试技巧

### 关键日志过滤

```bash
# 过滤蓝牙状态
grep "BT_STATUS" log.txt

# 过滤音频相关
grep "AUDIO-DAC" log.txt

# 过滤配置读取
grep "USER_CFG" log.txt

# 过滤连接事件
grep "bt_connction_status_event_handler" log.txt
```

### 常见问题排查

1. **连接失败**
   - 检查 `BT_STATUS_START_CONNECT` 后是否有 `HCI_EVENT_CONNECTION_COMPLETE`
   - 检查 `ERROR_CODE_SUCCESS`

2. **音频无声**
   - 检查 DAC初始化日志
   - 检查 A2DP通道建立
   - 检查 音量设置

3. **音量不同步**
   - 检查 AVRCP音量同步日志
   - 检查 VM存储的音量值
